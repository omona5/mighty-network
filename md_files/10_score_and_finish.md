# 10. 점수 계산 및 게임 종료

## 목표

모든 트릭이 끝난 뒤 주공 팀과 수비 팀의 점수를 계산하고 승패를 판정한다.

## 구현 범위

- 점수 카드 정의
- 획득 카드 기반 점수 계산
- 프렌드 공개 여부 확인
- 주공 팀 구성
- 수비 팀 구성
- 목표 점수 달성 여부 판정
- 게임 종료 상태 전송

## 점수 카드 예시

룰은 모임 기준으로 조정해야 한다.

```text
A, K, Q, J, 10 등을 점수 카드로 볼지 결정 필요
```

## Cursor 서버 프롬프트

```text
마이티 서버에 점수 계산과 게임 종료 로직을 추가해줘.

요구사항:
1. 모든 플레이어의 hand가 비고 마지막 트릭이 끝나면 게임을 종료한다.
2. 각 플레이어의 wonCards를 기준으로 점수를 계산한다.
3. 주공과 프렌드를 같은 팀으로 묶는다.
4. 프렌드 카드가 나오지 않았으면 프렌드 처리 룰을 RuleConfig에서 설정 가능하게 한다.
5. 주공 팀 점수가 targetScore 이상이면 주공 팀 승리로 판정한다.
6. 아니면 수비 팀 승리로 판정한다.
7. game_finished 이벤트로 결과를 방 전체에 전송한다.
8. 결과에는 팀, 점수, 승패, 각 플레이어 획득 점수를 포함한다.
```

## Cursor Unity 프롬프트

```text
Unity에 게임 종료 결과 화면을 추가해줘.

요구사항:
1. game_finished 이벤트를 받으면 결과 패널을 표시한다.
2. 주공 팀과 수비 팀을 구분해서 표시한다.
3. 각 팀 점수와 목표 점수를 표시한다.
4. 승리 팀을 강조한다.
5. 다시 대기방으로 돌아가는 버튼을 만든다.
```

## 완료 기준

- 마지막 트릭 후 게임이 자동 종료된다.
- 주공 팀과 수비 팀 점수가 계산된다.
- 목표 점수 달성 여부에 따라 승패가 표시된다.
- Unity에 결과 화면이 뜬다.

## 추가(세션 누적 스코어보드)

방 단위로 판마다 정산 점수를 누적한다.

- 주공 2배 / 프렌드 1배 / 야당 각 1배 (노프렌드면 주공=야당수×단위)
- 런·백런·노기루·노프렌드 배수 적용
- 대기방/결과 화면에 누적 점수 표시
- 방을 나가면 해당 플레이어 누적은 사라짐 (방에 남아 있는 동안만 유지)
- **새 플레이어 입장**: 기존 멤버 점수는 유지, 신규는 0부터
- **방장 전용 `reset_scores`**: 대기 중일 때만 전원 누적 점수를 0으로 초기화
