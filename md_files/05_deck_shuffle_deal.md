# 05. 서버 카드 덱 생성, 셔플, 배분

## 목표

게임 시작 시 서버가 카드 덱을 생성하고, 셔플한 뒤 5명의 플레이어에게 손패를 나눠준다.

## 구현 범위

- Card 데이터 구조 정의
- Deck 생성
- Shuffle 함수
- Deal 함수
- 각 플레이어 hand 저장
- 각 플레이어에게 자기 손패만 전송
- 공개 game_state에는 손패 내용 제외

## 카드 데이터 구조 초안

```javascript
{
  id: "S_A",
  suit: "SPADE",
  rank: "A",
  point: 1
}
```

## 주의사항

손패는 비공개 정보다.

따라서 서버가 모든 사람에게 보내는 `game_state`에는 각 플레이어의 카드 목록을 넣으면 안 된다.

```text
전체 공개 가능:
- 닉네임
- 준비 상태
- 현재 턴
- 낸 카드
- 점수
- 남은 카드 수

개별 전송해야 함:
- 내 손패
```

## 이벤트 약속

### Server → Unity

```text
game_state
your_hand
```

## your_hand 예시

```json
{
  "cards": [
    { "id": "S_A", "suit": "SPADE", "rank": "A" },
    { "id": "H_10", "suit": "HEART", "rank": "10" }
  ]
}
```

## Cursor 서버 프롬프트

```text
마이티 게임 서버에 카드 덱 생성, 셔플, 배분 기능을 추가해줘.

요구사항:
1. src/game/Card.js, Deck.js를 만든다.
2. 기본 트럼프 카드 52장을 생성한다.
3. 필요한 경우 조커 1장을 포함할 수 있게 옵션 구조를 둔다.
4. shuffle() 함수는 Fisher-Yates 알고리즘으로 구현한다.
5. 게임 시작 시 5명의 플레이어에게 카드를 배분한다.
6. 각 플레이어 객체에 hand 배열을 저장한다.
7. 각 플레이어에게는 your_hand 이벤트로 자기 손패만 전송한다.
8. game_state에는 다른 사람의 손패 내용은 넣지 말고 handCount만 포함한다.
```

## Cursor Unity 프롬프트

```text
Unity에서 서버가 보내는 your_hand 이벤트를 받아 내 손패를 화면에 표시하는 기능을 추가해줘.

요구사항:
1. CardView 프리팹 또는 임시 버튼 UI를 사용해 카드를 표시한다.
2. your_hand 이벤트를 받으면 기존 손패 UI를 지우고 새로 생성한다.
3. 카드에는 suit와 rank가 보이게 한다.
4. 아직 예쁜 카드 이미지는 없어도 된다.
5. game_state에서는 다른 플레이어의 handCount만 표시한다.
```

## 완료 기준

- 게임 시작 시 5명에게 카드가 배분된다.
- 각 플레이어는 자기 카드만 볼 수 있다.
- 다른 플레이어의 카드 내용은 보이지 않는다.
- 공개 상태에는 각 플레이어의 남은 카드 수만 보인다.
